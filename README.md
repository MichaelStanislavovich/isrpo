#Calculator

**Консольный калькулятор, написанный на языке "C++"**

Программа принимает на вход 2 целых числа и знак арифметической операции, выполняет вычислени и выводит результат
---
##Возможности программы

**Поддерживаемые операции:**
> [!IMPORTAINT]
>- Сложение `+`
>- Вычитание `-` 
>- Умножение `*`
>- Деление `/`

**Возмодные ошибки:**
> [!WARNING]
>- Invalid number
>- Invalid operator
>- Division by zero
---
##Запуск

Запуск программы осуществляестя введением в командную строку команды `./build/calculator <опеанд1> <оператор> <операнд2>`

###Пример работы программы
'''
Вводим команду:
> ./build/calculator 3 + 2

Вывод:
> 5
'''
