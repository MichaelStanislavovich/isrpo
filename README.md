# TODO Navigator


## Что делает плагин

TODO Navigator — расширение Visual Studio Code для поиска задач, записанных в комментариях **C++, JavaScript и TypeScript**. У него есть собственная вкладка на боковой панели, где задачи сгруппированы по файлам.

**Возможности:**

- поиск пометок `TODO` и `FIXME` с приоритетом `high`, `medium` или `low`;
- группировка найденных задач по файлам;
- переход в нужный файл и строку нажатием на задачу;
- два независимых фильтра: по типу и по приоритету;
- обновление после сохранения поддерживаемого файла и вручную кнопкой обновления;
- исключение служебных каталогов `node_modules`, `.git`, `dist`, `build`, `coverage`, `out`, `.next`.

## Формат комментариев

```cpp
// TODO [high]: добавить проверку пароля
// FIXME [low]: исправить формат даты
// TODO [medium]: покрыть функцию тестами
```

Поддерживаются отдельные однострочные комментарии `// ...` в файлах **C++:** `.cpp`, `.cc`, `.cxx`, `.h`, `.hpp`, `.hh`, `.hxx`; **JS/TS:** `.js`, `.jsx`, `.mjs`, `.cjs`, `.ts`, `.tsx`. Регистр букв и дополнительные пробелы могут отличаться: `// TODO[high]: текст` тоже подходит. Пометки без приоритета, без описания и комментарии после исполняемого кода в версии 0.2 не распознаются.

## Запуск через VS Code 

1. Откройте папку `todo-navigator` в VS Code.
2. Нажмите **F5** (или **Run and Debug → Запуск TODO Navigator**).
3. В окне **Extension Development Host** откроется тестовая папка `examples`.
4. Откройте слева вкладку **TODO Navigator** (иконка списка с галочками).
5. Раскройте файл **`demo.cpp`** (или `demo.hpp`, `demo.js`) и нажмите на любую задачу.
6. Измените комментарий в `examples/demo.cpp`, сохраните файл и проверьте обновление.
7. Нажмите на значки фильтров над списком задач, чтобы выбрать тип/приоритет.

> Если вкладка не появилась, проверьте, что тестовая папка `examples` открыта в новом окне, и используйте палитру команд «TODO Navigator: Обновить список».


## Установка расширения локально

Для установки в обычный VS Code нужен VSIX. Если доступен npm, выполните:

```bash
npm install -g @vscode/vsce
vsce package --no-dependencies
```

В VS Code: **Extensions - Install from VSIX** и выберите созданный файл. При публикации в Marketplace потребуется заменить учебный `publisher` на зарегистрированный идентификатор издателя.

## Структура и код

- `package.json` — описание расширения и регистрация вида, команд, кнопок.
- `src/parser.js` — разбор комментариев регулярным выражением и фильтрация.
- `src/scanner.js` — поиск подходящих файлов через VS Code API и чтение их содержимого.
- `src/tree.js` — отображение задач деревом «файл → задачи».
- `src/extension.js` — точка входа, команды, переход к строке и обновление после сохранения.
- `test/` — модульные тесты Node.js.
- `examples/demo.cpp`, `examples/demo.hpp`, `examples/demo.js` — готовые примеры для демонстрации на защите.
- `docs/STEPS.md` — этапы разработки, `docs/DEFENSE.md` — подготовка к защите.

## Ограничения 

- Поддерживаются C++ и JavaScript/TypeScript, но только отдельные `//`-комментарии заданного формата.
- Для простоты после сохранения повторно сканируется весь проект; на огромных репозиториях это может работать медленнее инкрементального обновления.
- Создание/удаление файлов вне механизма сохранения требует ручного обновления списка.
- Автотесты не заменяют проверку интерфейса внутри настоящего VS Code.
