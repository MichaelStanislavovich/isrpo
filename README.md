# Лабораторная работа №4

Тестирование программы WordCount

## Описание программы

Для лабораторной я взял программу на C++, которая считает количество строк, слов и байтов в текстовом файле.

Программа запускается из терминала. Ей передается название файла и при необходимости флаги:

- `--lines` или `-l` — количество строк
- `--words` или `-w` — количество слов
- `--bytes` или `-c` — количество байтов
- `--alnum` или `-a` — количество латинских букв и цифр

Если флаги не указывать, программа выводит строки, слова и байты.

Например:

```bash
./wordcount --words test.txt
```

## Файлы

- `main.cpp` — сама программа
- `test_wordcount.py` — тесты на Python
- `test_cases.md` — таблица тест-кейсов
- `results.txt` — результат запуска тестов

## Как запускать тесты

Я использовал Python и библиотеку `unittest`.

Для начала нужно поставить с++ компилятор

```bash
xcode-select --install
```

Далее открываем терминал и запускаем програму:

```bash
python3 -m unittest -v test_wordcount.py
```

Самому компилировать `main.cpp` перед этим не надо, тестовый файл делает это автоматически. Для проверки создаются временные текстовые файлы с разным содержимым.

## Что проверял

Всего написал 31 тест. Проверял работу с обычным текстом, пустым файлом, пробелами, переносами строк, числами и разными флагами. Так же проверил работу сразу с двумя файлами и случаи, когда аргументы указаны неправильно.

Ожидаемый результат сравнивается с тем, что реально вывела программа. Для этого используются проверки из `unittest`, в основном `assertEqual`.

## Результаты

При проверке исходной версии программы получилось:

- Всего тестов: 31
- Пройдено: 29
- Не пройдено: 2

Не прошли два теста:

1. Если написать только `--words` и не указать файл, программа ничего не выводит. Я ожидал сообщение об отсутствии файла.
2. Если указать файл, которого не существует, программа выводит нули вместо сообщения об ошибке открытия файла.

Все тест-кейсы и ожидаемые результаты отдельно расписаны в `test_cases.md`. Результат запуска находится в `results.txt`.
