## 1. Общее описание решения

Проект представляет собой консольный калькулятор, написанный на языке "C++"

Программа получает на вход 3 аргумента:

- Операнд 1
- Оператор
- Операнд 2


### Пример запуска:

В консоль вводится команда:
```bash
./build/calculator 3 + 2
```
Вывод:
```text
5
```

Также в программе предусмотренна проверка на корректность введенных данных:

Проверяется возможность таких ошибок как:

> [!CAUTION]
>- Invalid number
>- Invalid operator
>- Division by zero

**Поддерживаемые Операции**

| Оператор | Операция |
|----------|----------|
| `+` | Сложение |
| `-` | Вычитание |
| `*` | Умножение |
| `/` | Деление |

## 2. Описание функций

### `IsNumber`
Проверяет является ли аргумент корректным целым числом:

**Параметры:**

- `str` (const char*): строка, которую необходимо проверить.

**Возвращаемое значение:**

- `true` — строка является целым числом
- `false` — строка содержит некорректное значение

**Пример вызова:**

```cpp
bool result = IsNumber("-123");
```

*Функция вернет `true`*

---
### `IsNotOutOfRange`
Проверяет, находится ли переданное число в допустимом диапазоне типа `int32_t`

**Параметры:**

- `str` — строковое представление целого числа

**Возвращаемое значение:**

- `true` — число находится в допустимом диапазоне
- `false` — число выходит за допустимый диапазон

**Пример вызова:**

```cpp
bool result = IsNotOutOfRange("123");
```

---
### `Calculate`

Выполняет указанную арифметическую операцию над двумя указанными числами и выводит результат
'''
**Параметры**

- `lhs` (const char*): певый операнд
- `op` (const char*): арифметическая операция 
- `rhs` (const char*): второй операнд
**Возвращаемое значение:**
- `Отсутствует`

**Пример вызова:**
```cpp
Calculate("5" "*" "3")
```

**Результат**:
```text
15
```

При делении на 0 программа выводит:
```text
Division by zero
```
При некорректном операторе:

```text
Invalid operator
```

При некорректном числе:
```text
Invalid number
```

### `main`

Функция получает на вход аргументы командной строки и отправляет их в функцию `Calculate`
'''
**Параметры:**
- argc (int): количество аргументов командной строки,
- argv (char): сам массив аргументов командной строки

**Пример запуска:**

**Пример запуска:** 
`./build/calculator 2 + 3`
Получается:
```text
argv[0] = "./calculator"
argv[1] = "2"
argv[2] = "+"
argv[3] = "3"
```
**Результат:**

```text
5
```
